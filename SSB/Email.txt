Secondary PFI 2026 Re-setup Plan

Install PFI 2026

Complete fresh installation of PFI 2026 on the Secondary server.

Apply Required Patches

Apply Patch-01.
Apply Patch-06 for the required fixes, including ZAP/SPN compatibility.

Configure INI Files

Configure/update all required PFI INI configuration files.
Validate configuration against the Primary environment.

Update Service Account

Configure the required service account for all applicable PFI services.
Validate that services start successfully.

Restart Secondary Server

Restart the server after installation, patching, and configuration.
Verify all required PFI services are running successfully.

Failover to Secondary

Perform Azure failover from Primary to Secondary.
Confirm Secondary is active and accessible.

Validate Applications on Secondary

Test PFI functionality.
Test ZAP/SPN connectivity.
Validate other dependent applications/interfaces.
Confirm all three clients are functioning as expected.

Fail Back to Primary

After successful validation, perform failback from Secondary to Primary.

Final Validation

Retest PFI and all dependent applications after failback.
Confirm Primary is operating normally and no issues were introduced.
