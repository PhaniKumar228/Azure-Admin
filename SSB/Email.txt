Short Description

Azure SQL Managed Instance Migration - Permission Replication Assessment

Request application/database teams to execute the attached permission extraction scripts on the source SQL Server databases and share the output in Excel format. The collected permission details will be used to validate and replicate existing security configurations in Azure SQL Managed Instance (MI) after migration.

Notes

Please run the attached permission extraction scripts and provide the output in Excel format for the following databases:

Server Name	Database NameNTVPWVC0366	LINCPAM
NTVPWVC0366	T1PAM
NTVPWVC0365	IVSCPAM

A separate script has been provided for each database.

The output should include:

Database Users
Database Roles
Role Memberships
Object-Level Permissions
Database-Level Permissions
Schema Permissions (if applicable)

This information will be used to ensure all required permissions are replicated accurately in Azure SQL Managed Instance following migration.

Additional Notes
Please execute the scripts before the migration window.
Share the results in Excel format (.xlsx) with separate tabs for each script output.
Any custom roles, service accounts, application logins, or elevated permissions should be highlighted.
If any permission-related issues or execution errors are encountered, please notify the migration team immediately.
Security validation will be performed post-migration based on the submitted output.
